# 管理数据库用户和权限

| 命令                         | 核心用途                   |
| -------------------------- | ---------------------- |
| **GRANT**                  | 授予用户或角色对数据库对象的访问权限。    |
| **REVOKE**                 | 撤销之前授予的权限。             |
| **CREATE/ALTER/DROP ROLE** | 创建、修改或删除数据库角色（用户或用户组）。 |
| **SET ROLE**               | 将当前会话的用户标识设置为另一个角色。    |
