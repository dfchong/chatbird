# 外键的引用动作

| 参数                              | 简要说明                                                                     |
| ------------------------------- | ------------------------------------------------------------------------ |
| `MATCH FULL / PARTIAL / SIMPLE` | 多列外键的匹配方式，`SIMPLE` 为默认。                                                  |
| `ON DELETE` / `ON UPDATE`       | 引用行被删除或更新时的动作：`NO ACTION`、`RESTRICT`、`CASCADE`、`SET NULL`、`SET DEFAULT`。 |
