# 表的基本定义与标识

| 参数                   | 简要说明                                |
| -------------------- | ----------------------------------- |
| `TEMPORARY` / `TEMP` | 创建临时表，会话结束时自动删除（或按 `ON COMMIT` 设置）。 |
| `UNLOGGED`           | 创建无日志表，写入更快，但崩溃后数据会被清空，且不复制到备库。     |
| `IF NOT EXISTS`      | 如果同名表已存在，不报错，仅发出通知。                 |
| `table_name`         | 要创建的表的名称（可带模式名）。                    |
| `OF type_name`       | 基于已有的复合类型创建类型化表，列名和类型与类型定义一致。       |
