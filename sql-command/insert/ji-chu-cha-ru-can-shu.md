# 基础插入参数

| 参数名           | 简要说明                                                                     |
| ------------- | ------------------------------------------------------------------------ |
| `with_query`  | 定义可在 `INSERT` 查询中引用的一个或多个子查询（CTE）。                                       |
| `table_name`  | 要插入数据的现有表的名称（可带模式限定）。                                                    |
| `alias`       | 为 `table_name` 提供的替代名称，常用于 `ON CONFLICT DO UPDATE` 中避免与 `excluded` 表名冲突。 |
| `column_name` | 目标表中列的名称。可以按任意顺序列出，支持子字段或数组下标限定。                                         |
