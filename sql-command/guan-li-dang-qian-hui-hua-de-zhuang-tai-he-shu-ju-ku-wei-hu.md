# 管理当前会话的状态和数据库维护

| 命令                      | 核心用途                          |
| ----------------------- | ----------------------------- |
| **SET**                 | 修改当前会话的运行时参数，如 `search_path`。 |
| **SHOW**                | 显示运行时参数的当前值。                  |
| **VACUUM**              | 回收已删除行占用的存储空间，并可选择更新统计信息。     |
| **ANALYZE**             | 收集表的统计信息，供查询规划器使用。            |
| **LISTEN** / **NOTIFY** | 用于 PostgreSQL 的异步通知机制。        |
| **EXPLAIN**             | 显示一个语句的执行计划，用于性能分析。           |
