# 查询和修改表中的数据

| 命令         | 核心用途                                   |
| ---------- | -------------------------------------- |
| **SELECT** | 从表或视图中检索数据，是最常用的查询命令。                  |
| **INSERT** | 向表中插入新行。                               |
| **UPDATE** | 修改表中已存在行的值。                            |
| **DELETE** | 从表中删除行。                                |
| **VALUES** | 计算并返回一组行值，常与 `INSERT` 或 `SELECT` 配合使用。 |
| **COPY**   | 在 PostgreSQL 表和标准文件系统文件之间进行数据批量导入/导出。  |
