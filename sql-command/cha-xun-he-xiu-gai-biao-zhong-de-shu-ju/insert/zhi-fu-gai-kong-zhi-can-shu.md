# 值覆盖控制参数

| 参数名                       | 简要说明                                         |
| ------------------------- | -------------------------------------------- |
| `OVERRIDING SYSTEM VALUE` | 允许为 `GENERATED ALWAYS` 的标识列提供显式值，覆盖序列生成的默认值。 |
| `OVERRIDING USER VALUE`   | 忽略为标识列提供的值，改用序列生成的默认值。                       |
