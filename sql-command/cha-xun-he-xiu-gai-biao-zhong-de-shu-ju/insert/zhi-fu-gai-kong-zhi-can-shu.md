# 值覆盖控制参数

| 参数名                       | 简要说明                                         |
| ------------------------- | -------------------------------------------- |
| `OVERRIDING SYSTEM VALUE` | 允许为 `GENERATED ALWAYS` 的标识列提供显式值，覆盖序列生成的默认值。 |
| `OVERRIDING USER VALUE`   | 忽略为标识列提供的值，改用序列生成的默认值。                       |

1. `OVERRIDING SYSTEM VALUE`
   1. 系统强制自增列：generated always as identity
   2. 强行覆盖，写入用户提供的值
2. `OVERRIDING USER VALUE`
   1. `generated by default as identyty`
   2. `强行采用系统生成的自增序列值`
