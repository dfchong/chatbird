# 其他常用命令

| 命令                                  | 核心用途                        |
| ----------------------------------- | --------------------------- |
| **DO**                              | 执行一个匿名的代码块（通常是 PL/pgSQL）。   |
| **CALL**                            | 调用一个存储过程。                   |
| **PREPARE** / **EXECUTE**           | 预备并执行一个已准备好的语句，可提升重复执行时的性能。 |
| **DECLARE** / **FETCH** / **CLOSE** | 用于定义、遍历和关闭游标。               |
