# 管理事务的边界和属性

| 命令                                | 核心用途                |
| --------------------------------- | ------------------- |
| **BEGIN** / **START TRANSACTION** | 显式启动一个事务块。          |
| **COMMIT** / **END**              | 提交当前事务，使所有更改永久生效。   |
| **ROLLBACK** / **ABORT**          | 回滚当前事务，撤销所有未提交的更改。  |
| **SAVEPOINT**                     | 在事务内设置一个保存点，以便部分回滚。 |
| **SET TRANSACTION**               | 设置当前事务的特性，如隔离级别。    |
