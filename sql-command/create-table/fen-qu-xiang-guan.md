# 分区相关

| 参数                                       | 简要说明                                                                           |
| ---------------------------------------- | ------------------------------------------------------------------------------ |
| `PARTITION BY { RANGE \| LIST \| HASH }` | 将表声明为分区表，指定分区策略和分区键。                                                           |
| `PARTITION OF parent_table`              | 创建指定父表的一个分区。                                                                   |
| `FOR VALUES partition_bound_spec`        | 定义分区的边界值（`IN` 用于列表分区，`FROM ... TO` 用于范围分区，`WITH (MODULUS, REMAINDER)` 用于哈希分区）。 |
| `DEFAULT`                                | 创建默认分区，用于存放不匹配任何其他分区的数据（哈希分区不支持）。                                              |
