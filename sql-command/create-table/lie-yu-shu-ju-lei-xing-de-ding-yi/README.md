# 列与数据类型的定义

| 参数                               | 简要说明                                                                  |
| -------------------------------- | --------------------------------------------------------------------- |
| `column_name`                    | 新建列的名称。                                                               |
| `data_type`                      | 列的数据类型，可包含数组说明符。                                                      |
| `COLLATE collation`              | 为列指定排序规则（仅适用于可排序数据类型）。                                                |
| `STORAGE { ... }`                | 设置列的存储模式（`PLAIN`、`EXTERNAL`、`EXTENDED`、`MAIN`、`DEFAULT`），控制是否内联、是否压缩。 |
| `COMPRESSION compression_method` | 设置列的压缩方法（`pglz` 或 `lz4`），仅对变长类型有效。                                    |
