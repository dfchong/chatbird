# JSON与JSONB

一、PG提供了二种JSON类型

1. 存储方式不同
2. 处理效率不同
3. 文本格式
4. 二进制格式

二、对比

|      | JSON         | JSONB   |
| ---- | ------------ | ------- |
| 存储方式 | 文本           | 二进制     |
| 写入速度 | 更快           | 稍慢      |
| 查询性能 | 较慢           | 极快      |
| 格式保留 | 保留           | 精简空格    |
| 重复键  | 保留           | 去重      |
| 索引支持 | 仅限特定字段的表达式索引 | 支持全文索引  |

三、选型建议

1. 99％选择JSONB
2. 需要保留空格和重复键的、大批量写入等情况下JSON
